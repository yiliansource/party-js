## Usage

Pass the element the sparkles should burst out of. Particles spawn across its whole area rather than from a single point.

```js
import { range, sparkles } from "party-js";

button.addEventListener("click", () => {
    sparkles(button, {
        count: range(40, 60),
        size: range(5, 10),
    });
});
```

You can find a complete list of options and their defaults in the [reference](/api/effects/sparkleoptions/).
