## Usage

Pass the element the confetti should come from. The confetti shoots out of the middle of the element, fast and mostly along its `angle`. Drag slows it down within a fraction of a second, and it then flutters down slowly like paper, swaying as it tumbles.

```js
import { confetti, range } from "party-js";

button.addEventListener("click", () => {
    confetti(button, {
        count: range(40, 60),
        spread: 70,
    });
});
```

You can find a complete list of options and their defaults in the [reference](/api/effects/confettioptions/).
