## Usage

Pass the element the confetti should come from. Particles spawn across its whole area rather than from a single point, so a wide button gets a wide burst.

```js
// main.js
import { confetti, range } from "party-js";

button.addEventListener("click", () => {
    confetti(button, {
        count: range(40, 60),
        spread: 70,
    });
});
```

## Options

Every option has a default value, and can accept fixed values or a [sampler](/concepts/samplers/).
